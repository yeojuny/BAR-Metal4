# BAR Metal4 v1.11.0

Experimental native Metal 4 BAR for Apple Silicon Macs, macOS 27 or later. This release uses verified candidate **204**, combining 202 and 203 on preserved 201. Defaults: **AA 0x, VSync off**.

```sh
brew tap yeojuny/bar-metal4
brew install --cask yeojuny/bar-metal4/bar-metal4
open "/Applications/BAR Metal4.app"
```

Already installed? Run `brew update` and `brew upgrade --cask yeojuny/bar-metal4/bar-metal4`.

[Installation, content-retry repair, validation and limitations](docs/RELEASE-1.11.0.md) · [Download v1.11.0](https://github.com/yeojuny/BAR-Metal4/releases/tag/v1.11.0) · [Licenses and provenance](NOTICE.md)

No GitHub account or token is required. Homebrew installs pinned game content; first launch copies it locally for each user. Allow at least 10 GB free. Existing settings and saves are preserved. The app is ad-hoc signed and not notarized; macOS may require Privacy & Security > Open Anyway. Public multiplayer, full pixel parity and gameplay on other devices remain unverified.

The repository provides corresponding engine source, packaged lobby source-map originals, distribution scripts and upstream licensing. Earlier source baselines remain in Git history and docs. Private backup histories and raw conversations are not part of this public repository.
