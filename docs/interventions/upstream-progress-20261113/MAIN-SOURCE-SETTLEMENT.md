# Exact main-source settlement ownership (joined path)

The admitted ordinary draw now moves its main rollback owners into an allocated
per-submission record before transferring recorder ledgers or entering rendering:
opaque model, original shadow, ground, shield journal, environment/cube stage,
and dynamic-water pre-finalization receipt. Pointer identities are checked
against the sealed frame. Dynamic-water uses exact material identity plus draw
and update identity because finalization legitimately creates a new frame object.

The Session durably retains this record before any Begin. Failed-Begun work keeps
it quarantined alongside existing failed admission state. A pre-Begin exception
or hidden/no-Begin fallback validates all destinations and context epoch before
any ledger restoration, then swaps all source owners back without throwing.
No prior frame can overwrite occupied younger destinations. Zero draw identities
remain supported. Successful deferred acceptance releases only this record;
sealed rendering/GPU owners already retain its inputs. Synchronous completion
restores historical pending ownership before existing completion cleanup.

Shield journal transfer is explicit no-throw swap, including registry and epoch,
not reconstruction from a const rendering receipt. Previous retirement callbacks
continue using exact held ledgers; they cannot clear the detached current dynamic
receipt via Session. Existing reset/shutdown first require safe GPU retirement.

This is NOT historical asynchronous abort. Legacy refraction, current Lua abort,
and other current-frame cleanup still require joined execution. Renderer stack
handoff callbacks and Game's queued-versus-presented result also remain work for
P5. No enqueue or overlapping simulation is enabled here.

Validation: real journal/context/registry settlement tests cover every occupied
destination, epoch mismatch, detached reuse, whole-group exact restore, draw-zero
and durable exception retention. SceneBridge host C++ syntax and structural
preflight/transfer/restore/quarantine wiring checks. No native Metal execution,
full app build, visual parity or performance acceptance.
