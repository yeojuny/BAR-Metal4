# Remaining problems and next measured questions

1. Decide the desired shader/material interface before optimizing its implementation. Start from the three shared program/material/execution contracts and the actual consumer, not a wholesale renderer rewrite. The AST translator accepts a small typed expression subset; broader GLSL/control flow/resources/stage compatibility remain separate work.
2. Q same-session delete/link/set-uniform ownership and invalidation are unverified. F2's user-widget DisableWidget API is unavailable; F3 only proves fresh-profile initial values. Repair that fixture in an explicitly authorized future run, preserve F2, and test original program generation, slot1 layout and resource owner changes. Do not describe F3 as hot reload.
3. Q's CUS unit/pass0 GPU binding reuse is disabled and adds per-draw allocations. Actual activation, hit/miss/admission population, exact source/version/readiness, allocation/argument-table costs, and representative performance remain unmeasured. Do not infer this from S's type-fact hit counts.
4. S only caches CPU positive final-model type evidence. Preserve exact weak owner/address/control block, validated pixels, current lease/context/submission and bounded capacity. Texture/sampler/registration/readability/order/GPU completion must remain live. Measure lookup/stack overhead and broader source populations before generalizing.
5. The S ABBA does not establish an FPS gain. Keep B1 and opposite-sign paired differences. A future CPU-time study needs comparable power mode and a real clock; count-only wallNs0 is unavailable, not free. Statistical no-regression and whole-frame numeric equivalence are open.
6. Prior dark/blur rectangular bands persist in the representative images; this checkpoint did not diagnose or fix them. Q identity/variant screenshot differences also contain clouds/water/pause-label movement. Do not infer exact pixel equivalence.
7. R selected OriginalModelImage using valid all-thread stack witnesses; those inclusive scopes overlap. Terrain-height cost has insufficient measurement and was not selected. Larger GPU retirement/encode questions remain separate; changing queue depth or GPU resource lifetime needs its own ownership/order/completion proof and controlled measurement.

No new experiment is authorized by this preservation branch itself. The current public release and Homebrew remain v1.11.3. Use a separate private runtime and fresh profile if future testing is requested.
