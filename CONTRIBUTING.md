# Help wanted

Open an issue here with one bounded problem and a reproducible example before a substantial change.

1. **Portable build and distribution:** reproduce engine configuration from the published snapshot; identify missing dependency pins and package a redistributable, self-contained app for a dedicated Homebrew cask.
2. **Visual correctness:** compare one pass/effect at a time with the original rendering contract; document conditions and expected/actual behavior.
3. **Resource lifetime and residency:** investigate allocation, residency registration and completion costs without removing safety waits or reducing visual quality.
4. **Matched performance measurement:** separate CPU/loop diagnostics from physical FPS; hold camera, content, settings and power conditions fixed.
5. **Source review:** small, attributable fixes with regression evidence and appropriate upstream license notices.

Include source revision, OS/SDK/compiler, hardware, exact commands and a short sanitized error or minimal example. Label untested work clearly. Disclose AI assistance and what a human actually verified. These are requests for collaboration, not a claim that all local development is complete. Follow upstream AI/contribution policies if proposing any separate upstream submission.
